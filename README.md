## Description

Shaders are cinematic, playful, realistic, beautiful. That's what Iris was here for. The only problem? It won't run with VulkanMod. If you attempt to do that, Minecraft would just give up and crash. So what if you can just fork Iris and make it so that they will both play nice? That's the purpose of this fork.
